# Golden Analytical Layer Data Specification

This folder documents the Golden Analytical Layer generated by the cleaning and entity resolution pipeline.

## Core Golden Tables

### 1. `gold_accounts`
- **Primary Key**: `account_id`
- **Description**: Standardized account dimension table with static loan features, current DPD, and risk segment.

### 2. `gold_payments`
- **Primary Key**: `payment_id`
- **Foreign Key**: `account_id`
- **Description**: Fact table containing valid, non-duplicate SUCCESS payments with normalized `Asia/Kolkata` IST timestamps (`business_date`, `business_month`).

### 3. `gold_interactions`
- **Primary Key**: `interaction_id`
- **Foreign Keys**: `account_id`, `borrower_id`, `agent_id`
- **Description**: Unified interaction event stream spanning Voice calls, WhatsApp messages, SMS notifications, and Field Visits.

### 4. `gold_eligible_population`
- **Primary Key**: `account_id`
- **Description**: Unfiltered denominator population used for conversion rate, contact rate, and recovery rate computations.
